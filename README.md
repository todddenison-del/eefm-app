# EEFM App

Public, privacy-separated PWA shell for EEFM Mobile.

This repository intentionally contains **no private expedition data**.

Private itinerary, reservation, operational, and research data are imported locally on the user's device from a JSON package and stored in browser/app local storage.

Do not commit:
- confirmation numbers or record locators
- passport information
- hotel entry codes
- ticket barcodes / dynamic QR codes
- personal contacts
- medical or insurance identifiers
- passwords, authentication secrets, or payment-card data
